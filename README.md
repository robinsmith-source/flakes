# NixOS Configuration

Multi-machine NixOS flake.

| Host | Hardware | Environment |
|------|----------|-------------|
| `laptop` | Lenovo Ideapad 5 Pro 14ARH7 (Ryzen 6000 / Radeon 680M) | Niri + Noctalia |
| `desktop` | Ryzen 7 7800X3D + Radeon RX 7800XT | Niri + Noctalia |

**Stack:** Niri · Noctalia Shell · Alacritty · Fish · Neovim (LazyVim) · Home Manager

---

## Repo structure

- `/config` — dotfiles deployed to `~/.config` via Home Manager
- `/devices` — per-device NixOS configs and `hardware-configuration.nix`
- `/home` — Home Manager modules: base (`common.nix`), shell, and DE-specific
- `/modules` — shared NixOS modules with `workstation.*` enable options

```
flake.nix
devices/
  laptop/
    default.nix                    # Imports modules, enables workstation options
    hardware-configuration.nix     # Generated by nixos-generate-config
  desktop/
    default.nix
    hardware-configuration.nix
modules/
  baseline.nix                     # workstation.baseline: nix, boot, fonts, audio, BT
  niri.nix                         # workstation.niri: greetd, portals, Wayland env
  hardware-amd.nix                 # workstation.hardware-amd: amdgpu, ROCm
home/
  common.nix                       # Base HM: GTK, Qt, cursor, alacritty, neovim, git, btop
  fish.nix                         # Fish shell + starship
  niri.nix                         # Niri + Noctalia HM: settings, KDL deployment
config/
  niri/
    config.kdl                     # Root config — includes from cfg/
    noctalia.kdl                   # Noctalia color overrides
    cfg/                           # Shared niri KDL
      autostart.kdl                keybinds.kdl
      layout.kdl                   rules.kdl
      gestures.kdl                 events.kdl
      animation.kdl                misc.kdl
    hosts/                         # Per-machine niri overrides
      laptop/
        display.kdl                input.kdl
      desktop/
        display.kdl                input.kdl
  nvim/                            # LazyVim config + matugen base16
  noctalia/                        # user-templates.toml
  fastfetch/                       # config.jsonc
```

## How it works

Each device imports the modules it needs and toggles them on:

```nix
# devices/laptop/default.nix
imports = [
  ./hardware-configuration.nix
  ../../modules/baseline.nix
  ../../modules/niri.nix
  ../../modules/hardware-amd.nix
];

workstation = {
  baseline.enable     = true;
  niri.enable         = true;
  hardware-amd.enable = true;
};
```

`flake.nix` composes HM imports per device — swap `niri.nix` for another DE:

```nix
laptop = mkWorkstation {
  deviceModule = ./devices/laptop;
  hmImports = [
    noctalia.homeModules.default
    ./home/common.nix
    ./home/fish.nix
    ./home/niri.nix       # swap for ./home/kde.nix etc.
  ];
};
```

## Installation

### 1 — Boot the NixOS minimal ISO

### 2 — Partition and format

```bash
parted /dev/nvme0n1 -- mklabel gpt
parted /dev/nvme0n1 -- mkpart ESP fat32 1MiB 1GiB
parted /dev/nvme0n1 -- set 1 esp on
parted /dev/nvme0n1 -- mkpart primary 1GiB 100%

mkfs.fat -F 32 -n BOOT /dev/nvme0n1p1
mkfs.ext4 -L nixos  /dev/nvme0n1p2
```

### 3 — Mount

```bash
mount /dev/disk/by-label/nixos  /mnt
mkdir -p /mnt/boot
mount /dev/disk/by-label/BOOT   /mnt/boot
```

### 4 — Generate hardware config

```bash
nixos-generate-config --root /mnt
```

### 5 — Clone and install

```bash
nix-shell -p git
git clone <your-repo-url> /mnt/etc/nixos
cd /mnt/etc/nixos
cp /mnt/etc/nixos/hardware-configuration.nix devices/laptop/hardware-configuration.nix
```

### 6 — Personalise

| File | What to change |
|------|----------------|
| `flake.nix` | `username` |
| `modules/baseline.nix` | `time.timeZone`, `i18n.defaultLocale` |
| `home/common.nix` | `programs.git.settings.user.*` |
| `config/niri/hosts/laptop/display.kdl` | monitor name, mode, scale |
| `config/niri/hosts/laptop/input.kdl` | keyboard layout |

### 7 — Install

```bash
nixos-install --flake /mnt/etc/nixos#laptop
reboot
passwd robin   # set user password after first boot
```

## Day-to-day

| Command | Effect |
|---------|--------|
| `sudo nixos-rebuild switch --flake .#laptop` | Apply changes |
| `sudo nixos-rebuild build-vm --flake .#laptop` | Build QEMU VM for testing |
| `nix flake update` | Update all inputs |
| `sudo nix-collect-garbage --delete-older-than 7d` | Clean old generations |
| `sudo nixos-rebuild switch --rollback` | Roll back |

## Adding a new machine

1. Create `devices/<hostname>/default.nix` — import modules and enable them
2. Add `hardware-configuration.nix` from `nixos-generate-config`
3. Add per-machine niri configs in `config/niri/hosts/<hostname>/`
4. Add a new entry in `flake.nix`:

```nix
newbox = mkWorkstation {
  deviceModule = ./devices/newbox;
  hmImports = [
    ./home/common.nix
    ./home/fish.nix
    ./home/niri.nix
  ];
};
```

## Adding a new environment

1. Create `modules/<env>.nix` with `workstation.<env>.enable` option
2. Create `home/<env>.nix` for the HM side
3. Import the module in your device's `default.nix` and enable it
4. Swap the HM import in `flake.nix`

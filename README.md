# NixOS Configuration

Multi-machine NixOS flake — currently configured for:

| Host | Hardware |
|------|----------|
| `laptop` | Lenovo Ideapad 5 Pro 14ARH7 (Ryzen 6000 / Radeon 680M) |
| `desktop` | Ryzen 7 7800X3D + Radeon RX 7800XT |

**Stack:** niri · Noctalia shell · Alacritty · zsh · home-manager

---

## Flake inputs

| Input | Purpose |
|-------|---------|
| `nixpkgs` | NixOS unstable |
| `home-manager` | Declarative user environment |
| `niri` | [sodiboo/niri-flake](https://github.com/sodiboo/niri-flake) — NixOS/HM modules + binary cache |
| `noctalia` / `noctalia-qs` | [Noctalia shell](https://docs.noctalia.dev) — HM module for declarative config |

## Prerequisites

- A bootable **NixOS minimal ISO** (download from [nixos.org](https://nixos.org/download))
- Internet access on the target machine
- This repository cloned (or copied) onto the target machine

## Installation

### 1 — Boot the NixOS installer

Boot the target machine from the NixOS minimal ISO. The rest of these steps are run
inside the live environment as root.

### 2 — Partition and format the disk

Replace `/dev/nvme0n1` with your actual disk (`lsblk` to find it).

```bash
parted /dev/nvme0n1 -- mklabel gpt
parted /dev/nvme0n1 -- mkpart ESP fat32 1MiB 1GiB
parted /dev/nvme0n1 -- set 1 esp on
parted /dev/nvme0n1 -- mkpart primary 1GiB 100%

mkfs.fat -F 32 -n BOOT /dev/nvme0n1p1
mkfs.ext4 -L nixos  /dev/nvme0n1p2
```

### 3 — Mount

```bash
mount /dev/disk/by-label/nixos  /mnt
mkdir -p /mnt/boot
mount /dev/disk/by-label/BOOT   /mnt/boot
```

### 4 — Generate hardware configuration

```bash
nixos-generate-config --root /mnt
cp /mnt/etc/nixos/hardware-configuration.nix hosts/laptop/hardware-configuration.nix
```

### 5 — Clone this repository

```bash
nix-shell -p git
git clone <your-repo-url> /mnt/etc/nixos
cd /mnt/etc/nixos
```

### 6 — Personalise

| File | What to change |
|------|----------------|
| `flake.nix` | `username = "robin"` → your username |
| `modules/nixos/common.nix` | `time.timeZone` and `i18n.defaultLocale` |
| `modules/home/default.nix` | `programs.git.userName`, `userEmail`, noctalia `location.name` |
| `config/niri/cfg/input.kdl` | keyboard `layout`, `variant` |
| `config/niri/cfg/display.kdl` | monitor output name, `mode`, `scale` |
| `hosts/laptop/hardware-configuration.nix` | replace placeholder with output from step 4 |

> Run `niri msg outputs` after first boot to find your monitor name.

### 7 — First install

```bash
nixos-install --flake /mnt/etc/nixos#laptop --root /mnt
```

### 8 — Reboot and set your user password

```bash
reboot
# Log in as root, then:
passwd <your-username>
```

## Post-install

### Noctalia shell

Noctalia starts automatically via its systemd user service (configured through
home-manager). Check status:

```bash
systemctl --user status noctalia-shell
```

Settings live in `modules/home/default.nix` under `programs.noctalia-shell.settings`.
Full option reference: <https://docs.noctalia.dev>

To see the diff between your Nix-declared settings and any GUI-modified values:

```bash
nix shell nixpkgs#json-diff -c bash -c \
  "json-diff <(jq -S . ~/.config/noctalia/settings.json) \
              <(noctalia-shell ipc call state all | jq -S .settings)"
```

### Tailscale

```bash
sudo tailscale up
```

## Day-to-day commands

| Command | Effect |
|---------|--------|
| `sudo nixos-rebuild switch --flake .#laptop` | Apply configuration changes |
| `sudo nixos-rebuild test --flake .#laptop` | Apply without making it the boot default |
| `sudo nixos-rebuild build-vm --flake .#laptop` | Build a QEMU VM for testing |
| `nix flake update` | Update all inputs to latest |
| `sudo nix-collect-garbage --delete-older-than 7d` | Delete old generations |
| `nix store optimise` | Deduplicate the store |

### Rolling back

```bash
sudo nixos-rebuild switch --rollback
```

## Adding a new machine

1. Create `hosts/<hostname>/default.nix` and `hosts/<hostname>/hardware-configuration.nix`.

2. Add one line to `flake.nix`:

```nix
nixosConfigurations = {
  laptop  = mkSystem { hostname = "laptop"; };
  desktop = mkSystem { hostname = "desktop"; };
  newbox  = mkSystem { hostname = "newbox"; };
};
```

3. Run `nixos-install --flake .#newbox` on the new machine.

Host-specific overrides go in `hosts/<hostname>/default.nix`; everything else is shared.

## Repository structure

```
flake.nix                              # Inputs, mkSystem helper, nixosConfigurations
hosts/
  laptop/
    default.nix                        # Laptop-specific: lid, backlight, power profiles
    hardware-configuration.nix         # Generated by nixos-generate-config
  desktop/
    default.nix                        # Desktop-specific: GPU params
    hardware-configuration.nix
modules/
  nixos/
    common.nix                         # Shared NixOS: audio, BT, fonts, nix settings
    desktop/
      default.nix                      # workstation.niri module: greetd, portals, Wayland env
    hardware/
      amd.nix                          # amdgpu, microcode, Vulkan, ROCm
  home/
    default.nix                        # home-manager: GTK, Qt, cursor, alacritty, neovim,
                                       # zsh, git, btop, noctalia (declarative), niri config
config/
  niri/
    config.kdl                         # Root config — includes from cfg/
    noctalia.kdl                       # Niri colors (Noctalia scheme)
    cfg/
      autostart.kdl                    # Startup apps (noctalia via systemd)
      keybinds.kdl                     # All keybindings (noctalia IPC)
      display.kdl                      # Monitor outputs
      input.kdl                        # Keyboard layout, touchpad
      layout.kdl                       # Gaps, presets, window rules
      rules.kdl                        # Corner radius, layer rules
      gestures.kdl                     # Touchpad gestures
      events.kdl                       # Lid close → lock
      animation.kdl                    # Window/workspace animation tuning
      misc.kdl                         # CSD, env vars, debug flags
  nvim/
    init.lua                           # Entry point — LazyVim + matugen
    stylua.toml                        # Lua formatter config
    .neoconf.json                      # Neoconf/neodev settings
    lua/
      config/                          # LazyVim config (lazy.lua, options, keymaps, autocmds)
      plugins/
        base16.lua                     # base16-nvim + matugen integration
      matugen-template.lua             # Template for Noctalia → nvim colorscheme
      matugen.lua                      # Generated (DO NOT edit — written by Noctalia)
  noctalia/
    user-templates.toml                # User theming templates (nvim base16)
  fastfetch/
    config.jsonc                       # Custom fastfetch layout
```
